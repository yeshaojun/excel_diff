- 重写了文件显示逻辑
- 使用 file-list-item 样式显示文件信息

### 2. 上传文件之后，文本与文件信息显示样式不合理

- 文件大小使用独立的标签显示
- 改进删除按钮的样式和位置

- 修改单元格：红色背景 + 红色文字 + 加粗
- 删除单元格：粉色背景 + 棕色文字 + 删除线
- 无变化单元格：白色背景 + 黑色文字

- 添加图例说明不同颜色标记的含义

### 5. 变更结果使用中文，且希望美化展示方式
- 全部结果中文化
- 使用美化的卡片式展示变更项
- 每个变更显示工作表、单元格、类型、修改前、修改后
- 添加统计概览卡片
- 改进整体布局和视觉效果
- 响应式设计

## 🎯 使用步骤

### 1. 上传文件
1. 点击"基准文件"区域上传基准 Excel
2. 点击"对比文件"区域上传一个或多个对比 Excel
3. 文件信息会显示文件名和文件大小

### 2. 设置选项
勾选需要的选项：
- 忽略大小写：不区分大小写对比文本
- 去除空白字符：自动去除文本前后空白
- 忽略空单元格：跳过没有内容的单元格

### 3. 选择输出格式
选择您需要的输出格式：
- 文本：人类可读的文本报告
- JSON：程序可处理的结构化数据
- Markdown：适合文档的格式
- CSV：适合数据分析的格式

### 4. 开始对比
点击"开始对比"按钮，等待处理完成

### 5. 查看对比结果
对比完成后，会显示：
- 变更统计卡片
- 详细的变更列表（每个文件独立卡片）
- 美化的变更详情展示

### 6. 下载和预览

下载报告：点击"下载报告"按钮下载文本结果

下载带标记的Excel：
1. 点击"下载带标记的 Excel"按钮
2. 等待文件下载完成
3. 点击"在线预览"按钮查看
4. 在预览窗口中查看带颜色标记的 Excel

在线预览：
- 绿色背景 = 新增单元格
- 红色背景 = 修改单元格
- 粉色背景 = 删除单元格

## 🎨 颜色标记说明

| 变更类型 | 背景颜色 | 文字颜色 | 其他样式 |
|---------|---------|---------|---------|
| 新增 | 浅绿色 (#90EE90) | 深绿色 (#006400) | 加粗 |
| 修改 | 浅红色 (#FF6B6B) | 深红色 (#8B0000) | 加粗 |
| 删除 | 浅粉色 (#FFC0CB) | 深棕色 (#8B4513) | 删除线 |
| 无变化 | 白色 (#FFFFFF) | 黑色 (#333333) | 无 |

## API 端点

### 对比Excel文件
POST /api/compare

参数：
- base: 基准 Excel 文件
- targets: 对比 Excel 文件（多个）
- options: 对比选项（JSON 格式）

### 生成带标记的Excel文件
POST /api/export-marked-excel

参数：
- base: 基准 Excel 文件
- targets: 对比 Excel 文件（第一个）

### 健康检查
GET /api/health
